# Gun Motor Madiun

## Deskripsi Singkat

Website ini merupakan sistem informasi berbasis web untuk **Gun Motor**, sebuah bengkel mobil profesional di Madiun. Sistem ini dirancang untuk memberikan informasi layanan kepada pelanggan.

## Landing Page

**Website Publik (Landing Page)** memiliki halaman interaktif yang menyajikan profil bengkel, jenis layanan, paket perawatan berkala, galeri fasilitas, dan kemudahan akses konsultasi langsung via WhatsApp bagi pelanggan.
